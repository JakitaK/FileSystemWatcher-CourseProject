# FileSystemWatcher-CourseProject


A Java-based application that monitors file system activity in real time and logs events such as file creation, deletion, and modification.

## Overview

This project tracks file changes and stores event data in a SQLite database. It also includes a graphical user interface for viewing and querying file activity.

## Features

- Real-time file monitoring  
- Tracks create, delete, and modify events  
- Stores data in SQLite database  
- GUI for viewing and querying file events  
- Export functionality for logged data  

## Technologies Used

- Java  
- SQLite  
- Java Swing  

## How to Run

1. Clone the repository  
2. Open the project in your Java IDE (e.g., IntelliJ or Eclipse)  
3. Run the main application file  

## Notes

This project was developed as part of a team and focuses on building a system that handles file monitoring and event tracking.
